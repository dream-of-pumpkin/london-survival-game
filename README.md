# 伦敦入境生存 · London Survival（希思罗切片）

宫崎骏水彩风的 2D 横屏点击式英语生存游戏。**一个 HTML 文件装下全部逻辑**，素材（场景图、商品图、角色立绘）与英音配音放在 `assets/` 与远程 CDN。

线上试玩：**https://london-survival-game.pages.dev/**
（Cloudflare Pages，项目名 `london-survival-game`，主域自动跟随 `main` 分支的部署）

---

## 一、这是什么

一个用「入境求生」当壳子的英语口语练习器。玩家扮演一个刚落地希思罗的人，从机舱开始，过海关、取行李、出机场、找住处，然后在伦敦过日子——每一次点击都要听懂一句英文、选一句话说出去；说错了会被盘问，钱花光了会睡大街。

设计原则只有一条：**不背单词，直接在场景里活一遍**。

- 语言：对白、选项、标签全英文；中文只在「主动求助」或「答错」时出现
- 画风：吉卜力水彩手绘，纸纹底 + 淡水彩晕染，全站同一套视觉
- 屏幕：横屏 16:9（手机上请横过来）
- 体量：单文件 HTML（约 5.5 MB）+ 53 张场景/素材图

## 二、一局怎么走

```
机舱 s1 → 海关问答 s2 → 行李转盘 s3 → 出口 s4 → 住宿 s5 → 结局 s6 → 街区 HUB s7 → 店内 s8 → 景点 s9
```

1. **选角色**（不是选身份）
   - 留学生：£2,000 / 365 天 / 语言学校 6 个月，每周可兼职 20 小时
   - 游客：£5,000 / 90 天 / 不能打工
   - 背包客：£3,200 / 90 天 / 体力最好、钱最少
   - 角色只决定「你是谁、你带什么」；签证是另一回事。想跳过盘问直接出关，点「跳过海关盘问 · 直接出关」即可。
2. **海关五问**：护照 → 目的 → 停留时长 → 住哪 → 钱够不够。纯英文，答错才给你和官员双方那句话的中文。分数决定签证档位。
3. **行李转盘**：BELT 6，按一下取箱子。
4. **出口**：咖啡 £3.85 / 地铁 £5.90 / 打车 £75（开局现金有限，这里是第一次取舍）。
5. **住宿**：青旅床位 £35/晚、两个合租档（首付 £2,150 / £1,544）。
6. **街区 HUB（方案 A · 三栏仪表盘）**
   - 左栏：饥饿 / 生命 / 理智 三条状态 + 现金 + 签证剩余天数
   - 中栏：3×2 六个去处——咖啡馆、亚洲超市、便利店、中餐馆后厨（打工）、地铁（出行）、回青旅
   - 右栏：TODAY（今天还剩几个行动点）+ 固定开销提示
   - 每天 4 个行动点；住宿每晚固定扣 £35 + 伙食约 60/7
7. **四城地图 + 12 个景点**：伦敦（大英博物馆、塔桥、大本钟、白金汉宫）、爱丁堡（城堡、皇家一英里、亚瑟王座）、加的夫（城堡、海湾）、贝尔法斯特（市政厅、泰坦尼克博物馆、阿尔伯特钟）。每处先看场景图，点顶部按钮才出讲解，讲解带英文原句、中文释义和四个词。
8. **三店菜单化**：咖啡馆、亚洲超市、便利店都是先看货架再点单，商品带实物小图与价格。
9. **四种结局**：钱花光（broke）、签证到期（visa）、理智崩掉（collapse）、被带走（caught）。

## 五、技术结构

```
index.html          # 全部逻辑、样式、数据都在这里（约 5.5 MB，单文件）
assets/             # 53 张 jpg + 3 张透明立绘 png
README.md
```

**所有游戏数据都是 HTML 里的 JS 常量**，改内容只需改这些位置（搜索常量名即可）：

| 常量 | 内容 |
| --- | --- |
| `QUESTIONS` | 海关 5 题，每题 `en / cn / words / opts[{t, zh, ok, why}] / good` |
| `ROLES` | 三个角色：现金、签证天数、体力、难度 |
| `SIGHTS` | 12 个景点：英文讲解、中文释义、四个词、门票、车费 |
| `SPOTS` | 8 个街区去处（coffee / market / shop / kitchen / kitchenT / tube / sleep / toilet） |
| `SHOPS` | 3 家店、43 个条目（名称、价格、图、属性） |
| `MAPS` | 6 层地图 |
| `HOUSING` | 3 档住宿 |
| `VOICE_FILES` | 文本 → 语音文件名映射（160 条） |

状态对象是 `S`：`hunger / health / sanity`（0..1）、`cash / visa / score / qi / day / act`。

关键函数：`showScene()` 切场景、`renderHub()` 画街区、`renderQuestion()` / `answer()` / `resolveAnswer()` 跑海关问答、`pickSpotOpt()` 跑店内选项、`speak()` 管配音。

## 六、本地跑

直接双击 `index.html` 即可（纯前端，无构建、无依赖）。
若要在手机上看，用任意静态服务器起一个端口再访问，例如：

```bash
python -m http.server 8000
```

## 七、部署

Cloudflare Pages，直传模式（不是 GitHub 自动构建）：

```bash
npx wrangler pages deploy . --project-name=london-survival-game --branch=main
```

上线后主域会自动更新；验收时记得加 `?v=xxx` 破缓存。
